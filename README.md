# Агро-Севооборот

Инструмент поддержки решений для фермеров Северного Казахстана. Фермер обводит своё поле на карте
и сравнивает 3–4 варианта севооборота: что каждый даст **почве, воде и доходу** за 3–5 лет.
Расчёт идёт по спутниковым и климатическим данным NASA для этого поля и по агрономическим правилам,
у каждого из которых указан источник.

> **Это инструмент поддержки решений. Окончательное решение принимает фермер. Перед посевом посоветуйтесь с агрономом.**
> Сайт ничего не «советует»: вариант с лучшим взвешенным баллом лишь помечается как «лучше всего подходит вашим приоритетам», остальные остаются на экране.

Интерфейс на русском и казахском. **Казахский перевод требует вычитки носителем языка** (`frontend/src/locales/kk.json`, `backend/app/locales/*.yaml`).

## Быстрый старт

### Docker (рекомендуется)

```bash
cp .env.example .env        # необязательно: без .env работает демо и всё, кроме SMAP
docker compose up --build
```

Сайт: http://localhost:8080 · API: http://localhost:8000/docs

Демо (`/field?demo=1`) работает **без интернета**: все данные демо-поля лежат в `data/demo/`.
Проверено: контейнеры без доступа в интернет, демо проходит до скачивания PDF.

### Локально

```bash
make install    # Python 3.11 venv в backend/.venv + npm install
make dev        # бэкенд :8000 и фронтенд :5173 (Vite проксирует /api на бэкенд)
```

Прочие команды:

| Команда | Что делает |
|---|---|
| `make test` | 75 юнит-тестов бэкенда (`pytest`), включая тест казахских букв в PDF |
| `make build` | сборка фронтенда, включает проверку TypeScript в strict-режиме |
| `make lint` | `ruff` для бэкенда и скриптов |
| `make offline-check` | демо «анализ → сравнение → слои → PDF» с полным запретом сети |
| `make demo` | заново скачать данные демо-поля в `data/demo/` (нужен интернет) |
| `make smap` | заранее скачать ряд SMAP для поля (нужен Earthdata) |

`OFFLINE=1` в `.env` полностью запрещает внешние запросы: только `data/demo/` и `data/cache/`.

### NASA Earthdata (для SMAP)

1. Зарегистрируйтесь на https://urs.earthdata.nasa.gov (бесплатно).
2. Profile → **Generate Token**, скопируйте токен.
3. Впишите в `.env`: `EARTHDATA_TOKEN=...`
   (или `EARTHDATA_USERNAME` / `EARTHDATA_PASSWORD` и `pip install -e "backend[earthdata]"` — тогда токен получит `earthaccess`).

Без Earthdata всё работает, а запас влаги к посеву оценивается по осадкам NASA POWER — интерфейс об этом предупреждает.
Секретов в коде нет: только `.env` (в `.gitignore`).

## Как пользоваться

1. **Поле** — обвести контур на карте (инструмент многоугольника слева), загрузить GeoJSON/KML или перейти к координатам. Площадь считается сразу.
2. **История и приоритет** — что сеяли 3–5 лет, приоритет («максимальный доход», «сохранение влаги», «восстановление почвы»), горизонт 3–5 лет.
3. **Результат** — данные поля (засушливые годы, тренд NDVI, запас влаги, почва), карта со слоями NDVI / влажность / осадки, карточки вариантов с оценками 1–5 (у каждой кнопка с формулой, входными данными и источниками), свой вариант, прогноз по годам, стресс-тест засухой, объяснения простыми словами, PDF-план.

**Новое поле, первый запуск:** NASA POWER и SoilGrids приходят сразу (SoilGrids — до ~45 с),
NDVI MODIS и SMAP загружаются фоновыми задачами (~3 и ~6 минут на поле; проверено на поле в Костанайской области).
Сайт показывает прогресс и сам пересчитывает результат, когда данные готовы. Повторно — из кэша, за доли секунды.

| **ISRIC SoilGrids 2.0** | органический углерод, глина, песок, pH, 0–100 см | сетка 250 м, реальная детальность ниже | статичная карта | без ключа, бета | **модель машинного обучения**, не анализ почвы; сервис часто отвечает 503 или по тайм-ауту |
| GPM IMERG Final v07 | — (заготовка) | 0,1° | по CMR 1998-01-01 … 2025-09-30, задержка ~3,5 мес. | Earthdata | не подключено, используется POWER |
| Landsat C2 L2 (Planetary Computer) | — (заготовка) | 30 м | с 22.08.1982 | без ключа | не подключено, используется MODIS |

Каждый источник — класс в `backend/app/data_sources/` с единым интерфейсом `fetch(field, start, end)`, файловым кэшем
(`data/cache/<источник>/<sha256>.json`), демо-данными и запасным вариантом. **GPM и Landsat подключаются без
переработки архитектуры:** реализовать `_fetch_live` в `gpm.py` / `landsat.py` (инструкции в docstring), вернуть
данные в том же формате, что POWER / MODIS, и поставить `enabled = True`.

### Расхождения с таблицей из задания

- **MODIS**: не больше 10 композитов на запрос (ответ 400 при 11) — берём 10 композитов вегетационного сезона (DOY 129–273) на каждый год.
- **SMAP**: суточный файл весит ~650 МБ, поэтому не `earthaccess`-скачивание, а вырезка окна 3×3 ячейки через OPeNDAP (~3 с на день). Ссылку на файл берём из каталога CMR: у свежих гранул идентификатор в каталоге не совпадает с именем файла.
- **SSL ORNL**: сертификат `modis.ornl.gov` выпущен в цепочке emSign — нужен `certifi ≥ 2026.10.23`.
- **GPM IMERG Final** по каталогу CMR заканчивается 30.09.2025 (статус COMPLETE).

## Модель

Простая, прозрачная, детерминированная, без машинного обучения (`backend/app/model/rotation.py`).

```
урожайность  = база культуры × индекс области × (1 + эффект предшественника)
               × (1 + штраф за монокультуру) × коэффициент влаги поля
коэф. влаги  = RY(W поля) / RY(W области),  RY(W) = 1 − Ky·(1 − min(1, W / потребность))   (FAO-33)
W            = осадки май–август + запас продуктивной влаги к посеву
запас влаги  = норма области × (SMAP апрель–май / медиана SMAP)  — без SMAP по осадкам сентября–апреля;
               не больше влагоёмкости метрового слоя (SoilGrids + Saxton & Rawls 2006); после пара больше
доход        = урожайность × цена − затраты
индекс почвы = 100 + Σ (баланс азота / 10 кг + баланс гумуса / 0,25 т) − штраф монокультуры
```

- **Оценки 1–5** (почва, вода, доход, риск) нормируются от худшего к лучшему значению среди сравниваемых вариантов **и** вариантов по умолчанию — поэтому монокультура не получает «5 за почву», даже если сравнить её только саму с собой.
- **Приоритет** задаёт веса оценок (`model.yaml`); отдельные оценки от приоритета не зависят.
- **Засушливый год**: осадки май–август ниже 20-го перцентиля нормы 1991–2020 *или* аномалия ≤ −1σ. Доля — за последние 25 полных лет.
- **Стресс-тест**: любой год плана заменяется условиями засушливого года (2021, если он засушливый и по данным поля; иначе самый сухой год ряда).
- **Тренд NDVI**: максимум за сезон по годам, линейная регрессия; «растёт / снижается» только при p < 0,05.
- **Объяснения** собираются из шаблонов (`backend/app/locales/explain.yaml`) по сработавшим правилам, без LLM.

### Правила и их статус

Все числа — в `backend/app/rules/*.yaml`, у каждого `value`, `unit`, `source`, `status` и пояснение.
Загрузчик не запустит сервер, если у числа нет источника или статуса.

**Всего 88 значений: 14 проверены (`verified`), 74 — допущения (`assumption`)**, в интерфейсе помечены «требует проверки».

Проверены: цены чечевицы, гороха, подсолнечника (Минсельхоз РК, 27.07.2026); определение засушливого года и
год стресс-теста (из задания); порог p-value; опорные осадки трёх областей (рассчитаны по NASA POWER
скриптом `scripts/build_region_reference.py`); тривиальные значения для пара.

**Остались допущениями** (нужна проверка агрономом и по данным НПЦ им. А. И. Бараева / stat.gov.kz):

- базовая урожайность всех семи культур;
- затраты на гектар всех культур и пара;
- цены пшеницы (65–70 тыс., из задания), льна и рапса («от 200 тыс.», из задания), нута (не найдена);
- потребность во влаге и коэффициенты Ky (для пшеницы, гороха, подсолнечника значения FAO записаны по памяти — сверить с табл. 24 FAO-56; для чечевицы, нута, льна, рапса в таблицах FAO значений нет, принято Ky = 1);
- балансы азота и гумуса всех культур и пара;
- все 9 эффектов предшественников (числа для пшеницы после гороха/чечевицы — из опытов в Саскачеване, перенос на Казахстан — допущение; есть 18-летний опыт, где эффекта не было);
- индексы урожайности областей (по одному рекордному 2024 году) и нормы запаса влаги к посеву;
- прибавка запаса влаги после пара (25 %), штраф монокультуры (−10 %), пределы коэффициента влаги;
- шкала индекса почвы и веса приоритетов (это настройки модели, а не агрономия).

### Ограничения модели

- Цены и затраты постоянны на весь план; инфляция, субсидии, форварды Продкорпорации не учитываются.
- Удобрения, сорта, сроки сева, защита растений не учитываются: сравниваются севообороты при одинаковой технологии.
- Влага поля оценивается по данным с ячейками 9–50 км: локальные ливни и рельеф поля не видны.
- Формула FAO-33 линейна; при дефиците влаги, характерном для северной степи (потребность пшеницы ~550 мм против ~250 мм доступных), модель, вероятно, **недооценивает** потери в засуху.
- SoilGrids в верхних сантиметрах степных почв может завышать органический углерод; при гумусе > 8 % в слое 0–30 см интерфейс предупреждает.

## Демо-поле

- **Где:** пашня в Шортандинском районе Акмолинской области, ~9 км западнее п. Шортанды, между полевой дорогой и ручьём. Центр 51,6857° с. ш., 70,9317° в. д., **313,5 га**.
- **Контур** оцифрован вручную по снимку Esri World Imagery с отступом ~30 м от видимых границ. Это не кадастровая граница.
- **История** «пшеница много лет подряд» — учебный сценарий из задания; фактические посевы на этом поле не проверялись (так и написано в интерфейсе и PDF).
- **Данные** (`data/demo/`, ~880 КБ) скачаны с настоящих API 12.11.2026 скриптом `scripts/build_demo.py`:
  POWER 1981-01-01…2026-11-12; MODIS 270 композитов 2000–2026 по 60 пикселям поля; SMAP 730 суточных файлов 2015–2026 (503 дня с качественными измерениями); SoilGrids.

### Что показал расчёт демо (фактические цифры, не из питча)

| Показатель | Результат |
|---|---|
| Засушливые годы 2002–2026 | 2008, 2010, 2017, 2021, 2022, 2023 — **6 из 25, «каждый 4-й год»** |
| Тренд NDVI 2000–2026 | **стабилен** (наклон −0,0002/год, p = 0,96) |
| Запас влаги к посеву в обычный год | 110 мм (по SMAP), влагоёмкость метрового слоя ≈ 138 мм |
| Доход за 4 года, тг/га | пшеница по пшенице **−21 280**; пшеница→чечевица→пшеница→лён **82 408**; пшеница→горох→рапс→пар **57 050**; пшеница→нут→подсолнечник→пшеница **99 755** |
| Лучше всего подходит приоритету «доход» | вариант с чечевицей и льном (балл 4,24), почти вровень с вариантом с нутом и подсолнечником (4,23) |

**Сравнение с питчем.** «Каждый третий год засушливый» — **не совпало**: по данным поля и принятому определению засушлив
каждый 4-й год (24 %). «+25 % дохода за 4 года» — **в процентах сравнить нельзя**: при цене пшеницы 67,5 тыс. тг/т из
задания монокультура уходит в минус, а процент от отрицательной базы не имеет смысла. В абсолютных числах варианты
с бобовыми и масличными дают на 78–121 тыс. тг/га больше за 4 года. Это прямое следствие допущений о ценах и затратах:
закупочная цена пшеницы 3 класса урожая 2026 г. — 92–115 тыс. тг/т, и с ней разрыв будет меньше.

## Ретро-проверка

Полей с подтверждённой историей «пшеница после бобовых» пока **нет**, и страница так и пишет — никаких выдуманных
примеров. Заявки из формы сохраняются в `data/retro/submissions/` со статусом `unverified` и на сайте не показываются.
Проверенное поле публикуется, когда его JSON кладут в `data/retro/verified/` (формат: `id`, `name`, `region`,
`geometry`, `history`, `evidence`).
