# Ограничения модели и как их устранить

Составлено по итогам аудита (`docs/MODEL_AUDIT.md`, 12.11.2026). Приоритет: **высокий** — может изменить вывод
сравнения вариантов; **средний** — меняет величины, но не порядок вариантов в проверенных сценариях; **низкий** —
уточнение.

## А. Агрономические параметры

| # | Ограничение | Влияние | Как устранить | Приоритет |
|---|---|---|---|---|
| A1 | Урожайность альтернативных культур (чечевица, горох, нут, лён, рапс, подсолнечник) — оценки без областной статистики | В консервативном сценарии (−20 % урожая альтернатив, +30 % затрат, без эффекта бобовых) монокультура выигрывает по доходу — вывод меняется | Взять средние за 5 лет по области и культуре из БНС АСПиР (stat.gov.kz, динамические таблицы «урожайность по областям»); для урожайности по стерневому и паровому предшественнику — данные НПЦ им. Бараева или сортоучастков | высокий |
| A2 | Затраты на гектар всех культур и пара — без источника | Затраты +30 % снижают доход всех вариантов на 72–84 тыс. тг/га за 4 года | Технологические карты хозяйств или НПЦ им. Бараева; нормативы затрат для обязательного страхования (приказ МСХ, zakon.uchet.kz V1500011418) как нижняя опора; учитывать семена, удобрения, СЗР, ГСМ раздельно | высокий |
| A3 | Эффекты предшественников взяты из Канады; эффект бобовых зависит от азотного питания (0 % при полной дозе N, Zentner 1997; +15 % на хозяйствах Альберты; +18…+26 % в опытах) | При эффекте 0 % лучший по баллу вариант меняется (с чечевицей и льном → с нутом и подсолнечником) | Опыты НПЦ им. Бараева и Карабалыкской СХОС по предшественникам; ретро-проверка на полях с подтверждённой историей (страница «Ретро-проверка»); ввести дозу азота как вход модели | высокий |
| A4 | Цена нута не найдена; чечевица в документе МСХ без НДС, остальные культуры с НДС | Неоднородность ≈ 12 % в пользу культур с НДС | Приводить все цены к одной базе (без НДС или с НДС — по режиму налогообложения хозяйства); цену нута — из того же еженедельного обзора МСХ, когда она появится | средний |
| A5 | Цены постоянны на весь план; один срез на 27.07.2026 | Цены бобовых и масличных колеблются сильнее пшеницы (чечевица: 169 → 127 тг/кг за 1,5 года) | Использовать среднюю цену за 3–5 лет и показывать диапазон; стресс-тест по ценам рядом со стресс-тестом засухой | средний |
| A6 | Балансы азота — постоянные числа на культуру, не зависят от рассчитанной урожайности; фиксация бобовых не зависит от года | Индекс почвы не реагирует на засуху и урожай | Считать вынос как урожайность × содержание N (справочник агрохимслужбы); фиксацию — долей от биомассы (Walley et al., 2007), с поправкой на засуху | средний |
| A7 | Балансы гумуса: для бобовых (−0,3) и масличных сплошного сева источника нет; значения для пшеницы, подсолнечника и пара — точки из широких диапазонов (Саттыбаева, 2004) | Индекс почвы и вывод «по почве» | Данные стационаров НПЦ им. Бараева по балансу гумуса в севооборотах; модель баланса углерода (например, по массе пожнивных остатков) | средний |
| A8 | Потребность во влаге (ETm) — середины диапазонов FAO для вегетации 120–150 дней; измеренное испарение посевов в Северном Казахстане 194–259 мм | При 400 мм вместо 550 доход меняется < 2 %, порядок вариантов не меняется | Рассчитывать ETm = Kc × ET0 по данным поля: ET0 по Харгривсу из T2M_MAX/T2M_MIN NASA POWER, Kc по FAO-56 для фактических дат сева и уборки | низкий |
| A9 | Ky = 1 для чечевицы, нута, льна, рапса — значение FAO по умолчанию | Засухоустойчивость этих культур в стресс-тесте одинакова | Ky из полевых опытов по режимам орошения (если есть) или из моделей культур (AquaCrop имеет параметры для части культур) | низкий |

## Б. Конструкция модели

| # | Ограничение | Влияние | Как устранить | Приоритет |
|---|---|---|---|---|
| Б1 | Обрезка горизонта: затраты пара или бобовой в последнем году учитываются, а прибавка следующей культуры — нет | Вариант «пшеница → горох → рапс → пар»: −16 % дохода в год при горизонте 4 года против 5 лет | Оценивать полный цикл севооборота плюс один год; или добавить «остаточную стоимость» последнего года (эффект на следующую культуру); показывать доход в год, а не сумму | высокий |
| Б2 | Польза пара учтена только через влагу (+25 %, ≈ +27 мм); в Swift Current разница ≈ 43 мм, плюс выше эффективность использования воды и минерализация азота | Варианты с паром, вероятно, занижены | Отдельное правило «пшеница по пару» по опытам НПЦ им. Бараева; учёт минерализации азота на пару | средний |
| Б3 | Формула FAO-33 линейна и использует доступную влагу (осадки + запас) как замену фактического испарения | Не учитывает распределение осадков внутри сезона и жару в критические фазы (2021 г.: засуха с аномальной жарой) | Месячный водный баланс с Ky по фазам (FAO-33 даёт Ky по периодам роста); индекс жары по дням с T2M_MAX ≥ 30 °C в фазу налива | средний |
| Б4 | Удобрения, сорта, сроки сева, защита растений не моделируются | Сравнение верно только при одинаковой технологии; эффект бобовых зависит от азота (A3) | Ввести дозу азота и уровень технологии как входы; калибровать по данным хозяйства | средний |
| Б5 | Оценки 1–5 нормируются внутри набора вариантов (плюс опорные) | Оценка «5» означает «лучший из сравниваемых», а не «хороший» в абсолютном смысле | Показывать рядом абсолютные значения (уже показаны в подсказке); добавить абсолютные пороги для индекса почвы | низкий |
| Б6 | Веса приоритетов, шкалы индекса почвы, пределы коэффициента влаги — настройки без источника | Влияют на взвешенный балл и метку «лучше подходит» | Согласовать веса с фермерами и агрономами (опрос или парные сравнения); показать чувствительность к весам | низкий |

## В. Данные

| # | Ограничение | Влияние | Как устранить | Приоритет |
|---|---|---|---|---|
| В1 | Осадки NASA POWER — реанализ, ячейка ≈ 55 × 43 км | Локальные ливни поля не видны; засушливость года — характеристика района | Подключить GPM IMERG (0,1°; модуль-заготовка `gpm.py`) и данные ближайших метеостанций Казгидромета | средний |
| В2 | SMAP — верхние 5 см, ячейка 9 км (реально 33–40 км), с 2015 г. | Запас влаги в метровом слое — косвенная оценка через отношение к медиане | Сверить с весенними измерениями запасов влаги Казгидромета (агрометбюллетени) по ближайшим пунктам | средний |
| В3 | SoilGrids — модельная карта; на демо-поле гумус ≈ 8 % в слое 0–30 см, вероятно завышен | Влагоёмкость и сведения о почве | Агрохимическое обследование поля (обязательное для хозяйств, данные агрохимслужбы); загрузка своих анализов почвы в интерфейсе | средний |
| В4 | NDVI MODIS — зелёная масса, 250 м; не урожай | Проверка модели по NDVI подтверждает направление, но не величину потерь | Урожайность по полям хозяйства (книга истории полей) или по районам (БНС) для калибровки; Landsat 30 м (модуль-заготовка `landsat.py`) для небольших полей | высокий (для калибровки) |
| В5 | Ретро-проверка: нет ни одного поля с подтверждённой историей «пшеница после бобовых» | Эффекты предшественников не проверены на Казахстане | Собрать 10–20 полей через форму на сайте и партнёров (НПЦ им. Бараева, Продкорпорация) | высокий |
| В6 | GPM IMERG не подключён: чтение данных отвечает 403, пока в профиле Earthdata не одобрено приложение «NASA GESDISC DATA ARCHIVE» | Осадки только из POWER (~50 км) | Одобрить приложение в профиле Earthdata (Applications → Authorized Apps), реализовать `_fetch_live` в `gpm.py` | средний |
| В7 | Ваши почвенные данные (гумус, pH, состав) показываются рядом с SoilGrids, но в расчёт модели пока не входят | Влагоёмкость берётся из SoilGrids даже при наличии обследования | Пересчитать влагоёмкость по составу из обследования (Saxton & Rawls) и дать пользователю выбрать источник | средний |

## Г. Новые разделы интерфейса

| # | Ограничение | Влияние | Как устранить | Приоритет |
|---|---|---|---|---|
| Г1 | «Пригодность культур» — общая модельная оценка по тем же правилам, без валидации на урожайности хозяйств | Категории «благоприятно / ограничено» наследуют все допущения модели | Сверить с сортоиспытаниями и рекомендациями НПЦ им. Бараева по зонам | высокий |
| Г2 | Пороги уровней риска (σ осадков и температуры, перцентили NDVI, доли влажности) — в основном предварительные допущения (`model.yaml`, раздел `risk`) | Уровень «высокий / умеренный» условен | Согласовать с агрометеорологами Казгидромета; откалибровать по годам с официальными ЧС | средний |
| Г3 | Названия источников и единицы параметров в таблицах правил хранятся только по-русски (`rules/*.yaml`) | В казахском и английском интерфейсе таблицы правил частично на русском | Добавить переводы полей `unit` и названий источников в YAML | низкий |
| Г4 | Демо-песочница — общая для всех демо-пользователей только по данным, не по аккаунту; удаляется через 3 дня | Демо-анализы не сохраняются надолго | Это намеренно; для постоянной работы — регистрация | — |

## Что уже сделано для достоверности

- Каждое число в правилах имеет источник, статус и класс обоснованности; загрузчик не принимает число без них.
- Цены приведены к одному документу и одной дате.
- Независимый пересчёт засушливых лет, влаги, урожайности, дохода, азота и гумуса совпадает с моделью.
- Аудит воспроизводим одной командой и даёт одинаковые файлы при повторном запуске.
